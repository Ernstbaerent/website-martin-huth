Verfügbarkeit pflegen

Hier tragen Sie ein, an welchen Tagen Sie nicht für Termine zur Verfügung stehen. Auf der Website erscheinen diese Tage nur als „nicht verfügbar“ – ohne Grund. Wochenenden und Feiertage sind automatisch gesperrt.

Terminanfragen erhalten Sie per E-Mail an martin.huth@it-profis.biz.

Anmelden

Den Zugangsschlüssel bekommen Sie von Clemens. Er wird nur auf diesem Gerät gespeichert, bis Sie auf „Abmelden“ tippen.

Dann erinnert Sie diese Seite rechtzeitig, bevor der Schlüssel abläuft.

So geht’s

  1. Tippen Sie auf den ersten Tag, an dem Sie nicht können.
  2. Tippen Sie auf den letzten Tag. Für einen einzelnen Tag tippen Sie denselben Tag noch einmal an.
  3. Tippen Sie auf „Speichern“. Nach wenigen Minuten ist der Kalender auf der Website aktuell.

Zum Freigeben tippen Sie auf einen eingetragenen Tag oder löschen den Eintrag in der Liste.
